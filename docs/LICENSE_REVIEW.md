# 비용·저작권·배포 조건 점검

기존 정책 확인일: 2026-10-06. 파일 포함 현황 갱신: 2026-10-07.
기존 제작 아트는 사용자 요청으로 전부 삭제했다. 정책을 새로 검토했다는 뜻은 아니다.
시각 제작/참고 기준은 [dote.md](../dote.md)에 통합했다.

## 반드시 유지할 사용자 지시

**항상 무료로 진행하고, 자유롭게 배포할 수 있는 이용 조건을 확인한다.**
유료 API, 종량제 크레딧, 추가 구독, 유료 에셋·폰트, 유료 호스팅·서명 프로그램은
사용하지 않는다. 추가 비용 0원을 확인할 수 없는 도구는 호출하지 않는다.
네트워크 다운로드 허용은 결제나 유료 이용 허용이 아니다.
기존 이미지 3회 생성은 이 지시 이전에 수행되었다. 결제 내역이나 계정의
포함 사용량을 조회하지 않았으므로 해당 호출 비용을 0원이었다고 단정하지 않는다.
추가 이미지 생성 및 API fallback은 비용이 확인되지 않는 한 사용하지 않는다.

## 배포 전 남은 확인

- 200종 최종 디자인과 게임 명칭의 기존 작품·상표 유사성 검토. 현재 이름은 가칭.
- 생성 이미지의 출처·프롬프트·수정 이력 유지. 무조건 무저작권이라고 표시하지 않기.
- 사용하는 모든 에셋의 라이선스, 재배포·변경 허용, 필요한 고지를 명시.
- CC BY-NC, 개인 사용 전용, 출처·권리 불명 자료는 자유로운 배포 목표에 쓰지 않기.
- 코드 공개와 아트 재사용 허락은 구분. 원본 아트 권리를 임의로 CC0 양도하지 않기.
- 무료 저장소/릴리스 용량 내에서 배포. 유료 CI·클라우드·스토어 가입은 하지 않기.

**현재 결론:** 엔진 선택에는 무료 사용·게임 배포를 막는 라이선스 제한을 찾지
못했다. 다만 게임 전체의 저작권 검토가 완료된 상태는 아니다. 공개 배포 없음.
