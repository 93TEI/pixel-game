# 첫 들판 플레이 검증

2026-10-07: 기존 아트 전면 삭제로 그래픽 실행과 아래 플레이 절차는 현재 중단 상태다.
새 아트를 검토·연결한 후 재개한다. 시각 기준은 [DESIGN_AGENT.md](../DESIGN_AGENT.md).
과거 렌더링/통합 검사 통과 기록을 현재 아트 상태나 미술 승인으로 취급하지 않는다.
30–45분 수동 플레이·경제·보스 난도는 아직 검증하지 않았다.

## 직접 해볼 흐름

1. `sh tools/run.sh`를 실행하고 빈 슬롯으로 새 모험을 시작한다.
2. WASD로 마을 건물에 다가가 충돌을 확인하고 오른쪽 들판으로 나간다.
3. 야생 몬스터를 좌클릭해 지휘한다. 기본 공격과 자동 기술, 양쪽 체력을 본다.
4. 우클릭으로 동료가 복귀하는지 확인한다. 다시 클릭해서 전투를 잇는다.
5. 야생 몬스터가 약해지면 220 거리 안에서 F를 누른다.
   화면 확률은 실제 모델 확률이다. 실패하면 도구가 소모되며 다시 시도할 수 있다.
6. 포획 성공 후 2번 키로 새 동료를 출전시킨다. 3초 교체 대기를 확인한다.
7. Tab에서 개체 평가·기술 분기를 확인하고 기술 ON/OFF·우선순위를 바꾼다.
   메뉴를 열어 둔 동안 전투·쿨타임이 진행하지 않아야 한다.
8. 마을에서 E로 무료 회복하고 포획 도구를 구매한다. 필요하면 들판을 재생성한다.
9. 7마리 이상 보유하도록 포획해 보관함 전송/마을 교환을 확인한다.
10. F5로 안전하게 저장하고 종료 후 동일 슬롯을 이어한다.
    보유 동료·개체값·기술은 유지하며 체력/위치는 마을에서 복원한다.
11. 북동쪽 경기장(월드 x1408–1856, y96–416) 안에서 E로 보스 도전에 들어간다.
    아직 공통 보스 원형이다. 원형 전조와 3차례 출전, 전멸 복귀/승리 저장을 확인한다.
12. 승리 후 다음 지역이 데이터상 해금되지만 실제 다음 지역 지형/이동 UI는 미구현이다.

## 현재 가능한 자동 검증

```sh
sh tools/check.sh --model-only
```

이 명령은 데이터/모델만 검사하며 시각·통합 검사 통과를 의미하지 않는다.
`tests/test_playable.gd`, `tests/test_visuals.gd`, 캡처 스크립트는 보존했지만
삭제된 에셋에 의존하므로 새 아트/렌더러 기준으로 갱신한 후 실행해야 한다.
실제 저장을 건드리지 않는 격리된 테스트 폴더를 계속 사용한다.

## 다음에 기록할 것

- 첫 포획까지 걸린 시간, 동료 기절 횟수, 포획 도구 사용량.
- 30–45분 내 보스까지 도달 가능한지, 필요한 반복 전투량.
- 연못·건물 모서리의 이동/복귀 막힘과 적 공격의 지형 관통 여부.
- 일반 야생 AI 재공격·복귀 후 추격의 체감, 보스 전조 회피 가능성.
- 창 크기 변경, 디스플레이 배율, 한국어 폰트와 Windows 호환.
- 모든 시각/동작 검토는 [DESIGN_AGENT.md](../DESIGN_AGENT.md)의 절차를 따른다.
